编辑精选

如果只想先选几篇，可以从下面六篇开始：

  1. 强化学习入门：从 MDP、价值函数到 Q-learning：用一个纯 Python 小环境把状态、动作、回报、探索和时序差分连接起来，适合第一次系统理解强化学习。
  2. RAG 知识库评测：从检索命中到可信回答：不只讨论“答案好不好”，而是把失败拆到召回、重排、生成和拒答，适合建立 AI 工程评测意识。
  3. Codeforces 前缀和与差分四题：从区间摘要走到双层差分，可以同时练习边界处理、排序贪心与离线建模。
  4. 古典音乐中的和声张力：不要求先会读谱，从稳定、离开、紧张和解决四种听觉动作进入功能和声。
  5. Transformer 入门：从神经网络、自注意力到逐 token 生成：从矩阵形状和三 token 手算进入模型骨架，适合连接基础神经网络与大语言模型。
  6. Codeforces 贪心三题：排序、交换论证与局部最优：从三种不同的正确性依据入手，适合从“会写贪心”走向“能证明贪心”。

AI 与知识库

  • AdamW 原理 从自适应步长到解耦权重衰减：手算矩估计、偏差修正与参数缩放，比较 Adam 加 L2 和独立衰减的不同轨迹。

  • LayerNorm 原理 从特征轴到归一化梯度：沿最后特征轴统计，推导跨行共享参数与 epsilon 的影响，再放回 Transformer 的归一化位置。

  • PPO 原理 从概率比到裁剪梯度：承接 GAE，用分段梯度和 KL 反例区分目标裁剪与硬约束。

  • 主动学习 从不确定性采样到标注预算：承接标注一致性，精确比较阈值模型的三次主动查询与平均五次随机查询，不把查询集当作独立评测集。

  • BatchNorm 原理 从批次统计到训练推理差异

  • GAE 优势估计 从 TD 残差到采样边界：承接策略梯度，手算多步混合，分清外部截断的自举与跨回合传播。

  • 标注一致性 从双人混淆矩阵到 Cohen kappa

  • 卷积神经网络 从局部连接到共享权重的梯度

  • DQN 原理 从神经 Q 网络到经验回放与目标网络

神经网络方向可从反向传播理解“参数怎样从损失得到更新方向”，再比较 CNN 的局部共享与 Transformer 的注意力组合。数据方向先定义标注规则，再把一致性检查与质量评测分开。强化学习从表格 Q-learning 接到 DQN，也可以分支到策略梯度；RAG 则从 embedding 与语义检索进入外部证据链，强化学习不是它的前置要求。
