最近更新

  • 算法路线：先用 20C Dijkstra 与 1063B 0-1 BFS 比较不同边权下的最短路，再用 545E、449B、938D 最短路进阶三题 处理树边选择、特殊边去冗余与多源建模；随后通过 25D 并查集、1245D 电网规划 和 1167C、277A、1213G 并查集三题 扩展无向图、集合统计与离线询问；有向图由 510C 基础拓扑排序 进入 1385E、1572A、909E 三题；树结构从 115A、580C、1336A DFS 三题 和 1006E 子树区间 走到 1092F、1187E、1324F 换根 DP 三题，数组结构由 547B 单调栈 进入 5C、1313C2、1407D 栈与单调栈三题，再从 339D 单点线段树 走到 52C、380C、474F 线段树三题；数位 DP 则用 1036C、628D、55D 三题 比较计数、位置限制和 LCM 状态压缩。
  • 交响曲路线：先从 莫扎特第四十一 的对比与复调终曲出发，对照 贝多芬《田园》、勃拉姆斯第二 与 德沃夏克第八，再比较 勃拉姆斯第四 如何让短动机走向固定骨架上的连续变奏，并用 德沃夏克第九“自新大陆” 观察跨乐章主题记忆；之后连接 贝多芬第五 的短节奏细胞、贝多芬第七 的持续脉搏、柴可夫斯基第五 的跨乐章动机与 柴可夫斯基第六“悲怆” 的假终点和慢终曲；舒伯特“未完成” 辨析作品状态与听觉闭合，再延伸到 西贝柳斯第二、马勒第一、拉赫玛尼诺夫第二 和 布鲁克纳第四；音乐实验室 提供短实验和十五部作品的官方演出入口。
  • AI 学习路线：先用 Transformer 入门 打通神经网络、自注意力与逐 token 生成，再用 反向传播、自动微分与优化器 拆开模型怎样学习参数，之后进入强化学习、RAG 和 大模型推理时计算；如果想换一个方向，可从 钙钛矿太阳能电池 理解效率、界面与稳定性的关系。

编辑精选

如果只想先选几篇，可以从下面六篇开始：

  1. 强化学习入门：从 MDP、价值函数到 Q-learning：用一个纯 Python 小环境把状态、动作、回报、探索和时序差分连接起来，适合第一次系统理解强化学习。
  2. RAG 知识库评测：从检索命中到可信回答：不只讨论“答案好不好”，而是把失败拆到召回、重排、生成和拒答，适合建立 AI 工程评测意识。
  3. Codeforces 前缀和与差分四题：从区间摘要走到双层差分，可以同时练习边界处理、排序贪心与离线建模。
  4. 古典音乐中的和声张力：不要求先会读谱，从稳定、离开、紧张和解决四种听觉动作进入功能和声。
  5. Transformer 入门：从神经网络、自注意力到逐 token 生成：从矩阵形状和三 token 手算进入模型骨架，适合连接基础神经网络与大语言模型。
  6. Codeforces 贪心三题：排序、交换论证与局部最优：从三种不同的正确性依据入手，适合从“会写贪心”走向“能证明贪心”。

交互实验

这些小实验直接在浏览器中运行，不上传数据，也不需要外部服务：

  • 算法与决策：逐步执行二分答案、调节 ε 观察探索概率；
  • 网络与数据：逐报文走完 TCP 三次握手、从右向左判断 NumPy 广播、按分析问题选择图表；
  • 音乐与听觉：对比 3/4 与 6/8 的重音、试听四音动机的倒影、逆行与增值；
  • 交响曲配套练习：林间两束光：大小调色彩、舞步的回信：主题、变化与返回；
  • 动机与配器练习：湖面三音：短动机发展、远景渐明：音区与能量积累；
  • AI 工程：切换因果遮罩观察注意力归一化、根据失败现象定位 RAG 流水线环节。
