面对新题，先问哪个问题

这是一条知识依赖路线，不是难度严格递增的榜单。遇到题目时，先检查结构，再选择工具；下面每一行都需要验证右侧条件。

先问自己 候选工具 必须成立的条件
大量区间查询能否共享摘要 前缀和 / 差分 运算支持相应的累计与还原，注意在线和离线之别
能否随着右端点移动而只向前调整左端点 双指针 可行性或窗口代价具有所需单调性
猜一个答案后，能否快速判断可行 答案二分 判断结果在搜索区间中只有一次真假分界
未来只需要知道哪个状态 动态规划 状态信息足够，并且依赖有可处理的计算顺序
每次操作代价相同，目标是否为最少步数 BFS 状态规模可控；若裁剪搜索范围，需证明不会丢最优解
边有不同的非负代价，目标是否为总代价最小 Dijkstra 不含负权边；堆中旧记录需要识别
正确建模后，边权是否仅为 0 或 1 0-1 BFS 0 权入队首、1 权入队尾；仍需严格松弛
逐条加边，只需判断哪些顶点已经连通 并查集 普通并查集维护合并，不直接支持任意删边
要用最小总代价连接所有顶点 最小生成树 图需连通；虚拟选择可先转化为普通边
输入给出“谁必须先于谁”的约束 拓扑排序 有向图必须无环；还要先处理建图阶段的局部矛盾
多个零入度点同时可选，选择顺序是否影响代价 拓扑 DP / 分批贪心 先明确状态转移或批次费用，不能只求任意拓扑序
合并两个集合后能否直接更新答案 并查集 + 分量统计 统计量必须能由两个根的信息和合并事件推出；在线删边通常不适用
查询阈值递增时，可用关系是否只增不减 排序 + 离线并查集 允许重排询问并保存原下标；相同阈值要处理完所有合法边
查询只关心整棵子树 DFS 序与子树区间 访问必须完整处理子树后才返回；固定孩子顺序
条件只由当前根路径决定 DFS 路径状态 状态随边向下更新；已经非法的前缀才能安全剪枝
答案同时依赖节点位置和后代数量 深度 + 子树大小 向下记录深度，逆序或回溯汇总子树统计
每个元素能作为最值影响多大范围 单调栈 栈内候选需满足单调性；明确等值元素的边界归属
单点变化后是否只需重算有限层摘要 线段树 节点摘要可由两个孩子合并；明确结合顺序与单位元
一次修改完整覆盖许多连续位置 懒标记线段树 修改能直接作用于节点摘要，并可组合为待下传标记
区间答案是否依赖左右先后顺序 有序区间摘要 合并需满足结合律，但未必满足交换律；查询不能颠倒片段
数值上界很大，限制能否随十进制前缀更新 数位 DP 状态需概括已选前缀；用 tight 约束当前位，并明确前导零语义
能否放心舍弃其他选择 贪心 有交换论证、支配关系等正确性依据

图论路线可以连续阅读 520B：状态图与逆向贪心、20C：Dijkstra 与路径还原 和 1063B：位移守恒与 0-1 BFS，比较单位边权、一般非负边权与 0/1 边权怎样改变扩展顺序。1063B 的评分低于 20C，但它增加了资源状态压缩的建模训练。动态规划方向则由 状态设计与方案还原 衔接 Flowers 的计数与区间查询，再通过 1036C、628D、55D 数位 DP 三题 练习把巨大值域改写为逐位构造。

每道题怎样复盘

连通性分支从 25D：并查集与最少改路 开始，再到 1245D：虚拟源点与最小生成树。有向图分支先读 510C：字典序约束与拓扑排序，再用 1385E、1572A、909E 三题 比较定向构造、拓扑 DP 与分批贪心。树结构先用 115A、580C、1336A 三题 分清深度、路径状态和子树汇总，再进入 1006E：先序 DFS 与子树区间。数组结构分支先读 547B：单调栈与支配区间，再用 5C、1313C2、1407D 三题 比较失配边界、区间贡献与双单调栈 DP；需要在线修改时进入 339D：交替位运算线段树，最后通过 52C、380C、474F 三题 比较懒标记、非交换合并与复合数论摘要。

  1. 用一句话描述输入、目标与约束；
  2. 写出方法成立所依赖的条件；
  3. 主动测试最小值、临界值和重复值；
  4. 解释时间复杂度，而不只背结论；
  5. 修改一个条件，判断原方法是否仍然成立。
