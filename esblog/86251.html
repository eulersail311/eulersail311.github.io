双节点热网络 从耦合储能到双时间尺度

稳态热阻把温差与热流联系起来，集总热容再加入储能，得到单指数冷却。但两个物体之间传热有限时，即使每个物体内部都接近均温，也不等于两者能共用一个温度。

本文从单节点推进到双节点：分别记账、检查能量交换、找出两个衰减模态，再判断什么时候可以近似合并。所有参数和数值均为合成教学设定，不对应材料牌号、真实器件测量或热安全认证；正文不为内部数值核验展示程序。

两个热容，三种温度

节点1、2分别用T₁、T₂表示温度，热容C₁、C₂单位J/K。节点间热导G₁₂单位W/K，节点2向恒温环境T∞的热导G₂∞同样为W/K；热阻为相应热导的倒数。节点1没有直接向环境的通道，没有内部热源。

假设两节点各自内部近似均温，热容和热导为正常数；环境恒温；忽略辐射非线性、相变和质量交换。两个温度变量是建模选择，不是对连续温度场的自动精确离散。MIT热建模讲义第3—4页讨论热储能与增加集总节点的必要性，本文的双节点拓扑和算例另行构造。

同一条内热流，在两个账本中反号

定义θ₁=T₁−T∞、θ₂=T₂−T∞，温差单位K，数值也可用摄氏度差。由节点1流向节点2的热流为G₁₂(θ₁−θ₂)，由节点2流向环境为G₂∞θ₂。

方程H1：逐节点能量平衡

C₁ dθ₁/dt = −G₁₂(θ₁−θ₂)；C₂ dθ₂/dt = G₁₂(θ₁−θ₂)−G₂∞θ₂。

时间t单位s，左右两侧均为W。只对温差使用摄氏度差，不把绝对温度与温差混用。

两式相加，内部交换完全抵消。相对环境的储能E=C₁θ₁+C₂θ₂，满足dE/dt=−G₂∞θ₂。若θ₂>0，总储能下降；若节点2低于环境，环境可以向系统输入热量，所以不能把dE/dt永远非正写成无条件定理。

这也解释了瞬态不能套“串联热流处处相等”：节点2正在储能时，进入它的热流与离开它的热流可以不同，差额就是C₂dθ₂/dt。

  flowchart TD
 A[为每个均温节点写储能] --> B[同一内热流分别记正负]
 B --> C[加入外部边界热流]
 C --> D[相加检查内部项抵消]
 D --> E[再解耦合温度方程]

为什么两个衰减率都应为正

令α=G₁₂/C₁+(G₁₂+G₂∞)/C₂，单位s⁻¹；β=G₁₂G₂∞/(C₁C₂)，单位s⁻²。令θ∝exp(−rt)代入H1，特征方程为r²−αr+β=0。

公式H2：两个衰减模态

rₛ=(α−√(α²−4β))/2；r𝒻=(α+√(α²−4β))/2。

rₛ≤r𝒻，单位s⁻¹，时间常数分别为其倒数；指数中的rt必须无量纲。

正热容和正热导下，热导矩阵对应二次型G₁₂(θ₁−θ₂)²+G₂∞θ₂²，为正定；用热容平方根缩放后得到对称正定矩阵。因此两个衰减率实且为正。两节点热导不为零时耦合项非零，两率不同。

也可以用V=(C₁θ₁²+C₂θ₂²)/2检查符号，得到dV/dt=−G₁₂(θ₁−θ₂)²−G₂∞θ₂²≤0。V是数学上的二次型，单位J·K，不是储能E；把它叫作“系统热量”会混淆两种账本。若算出正指数增长，先查热流符号和边界条件，再怀疑求解器。

从同温初态算到两个不同温度

取C₁=C₂=1 J/K，G₁₂=G₂∞=1 W/K，T∞=20°C，初始T₁=T₂=30°C。初始内部温差为0，因此节点1初始降温率为0，节点2初始降温率为−10 K/s；相同初温不会保证此后相同温度。

此时rₛ=(3−√5)/2≈0.381966 s⁻¹，r𝒻=(3+√5)/2≈2.618034 s⁻¹。令Δ=r𝒻−rₛ，解析解为：

公式H3：本组教学参数的解析解

θ₁(t)=10[r𝒻 exp(−rₛt)−rₛ exp(−r𝒻t)]/Δ。

θ₂(t)=10[(r𝒻−1 s⁻¹)exp(−rₛt)+(1 s⁻¹−rₛ)exp(−r𝒻t)]/Δ。

系数10的单位为K。式中1 s⁻¹来自G₁₂/C₁，仅适用于本组参数，不能忽略量纲后当作通式。

时刻或检查项 节点1 节点2 含义
t=0 30°C 30°C 内热流为0
初始变化率 0 K/s −10 K/s 外边界先让节点2失去热量
t=1 s 27.866456°C 25.140367°C 内部开始形成温差
很长时间后 趋于20°C 趋于20°C 无热源且最终与环境平衡

将H3在0处代入并求导，可分别核对初态和H1；只检查两者最终都到20°C并不足以验证暂态正确。各节点温度一般是两个指数的线性组合，不能分别指定一个互不耦合的牛顿冷却时间常数。

合并热容为何可能拟合不好

若强行让T₁=T₂=T，得到C总=2 J/K、对外热导1 W/K，单节点模型为θ_L=10exp(−t/2)，时间常数2 s。它的初始总散热率与双节点一致，却让两个节点一开始都以−5 K/s变化，与H1不符。

t=1 s时，单节点温度为26.065307°C。它低估节点1约1.801149 K，高估节点2约0.924940 K。双节点剩余储能约13.006823 J，合并模型约12.130613 J；不仅局部温度不同，之后的总能量轨迹也已经分离。

初始同温、总热容相同、初始总散热率相同，都不是整个冷却曲线相同的充分条件。尤其当要判断内部节点的峰值或阈值时间时，只拿表面曲线拟合单指数可能掩盖内部滞后；本文没有据此对真实设备作安全判断。

何时才值得采用一个温度

先暂时忽略外部散热，两节点温差的衰减时间为τ内=C₁C₂/[G₁₂(C₁+C₂)]。合并后的外部冷却尺度约为τ外=(C₁+C₂)/G₂∞。当内部平衡远快于外部冷却、且每个节点自身的均温近似合理时，才有理由考虑单温度模型；初始温差很大时还要处理早期快模态。

本例τ内=0.5 s、τ外=2 s，只有四倍差距，不能把它当作明显分离。时间尺度比较是模型选择线索，不是通用误差百分比保证；实际精度还受几何、参数变化、接触热阻、辐射和传感器位置影响。

MIT关于物理建模假设的讨论强调，模型简化会抹去某些空间信息。把连续体分成两个节点比一个节点多保留一种内部温差，但也不自动保证已经足够。

  flowchart TD
 A[单指数无法解释内部与外部差异] --> B[检查各节点均温假设]
 B --> C[比较内部与外部时间尺度]
 C --> D[核对初始快模态]
 D --> E[按关心的温度与误差选模型]
 E --> F[需要时增加节点或改用分布模型]

自检与边界

节点1初始不降温，是否说明它与环境完全绝热？

不是。它通过节点2间接散热；最初两者同温，内部通道热流恰好为0，之后节点2先降温便形成传热驱动力。

二次型V递减，是否说明相对环境储能E在所有初态下都递减？

不能。V与E不同；当节点2低于环境时，环境能输入热量，dE/dt可以为正。

G₂∞=0时系统与环境断开，存在守恒的总储能及非零最终共同温度，H2的一个衰减率变为0；G₁₂=0时节点1与其他部分断开。这两种情形不满足前文正定收敛证明的严格正热导假设，应单独处理，不能把零除数藏进时间常数。
