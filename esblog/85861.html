集总热容 从冷却时间常数到 Biot 数

稳态导热里，流入与流出相等，材料内部不再积蓄能量。如果把温热的小物体放进较冷的流体，它的温度仍在变化，此时流出的热量来自物体储存的内能，不能继续套用“各处热流率都一样”的稳态结论。

本文用一个随时间变化的温度T(t)近似整个物体，推导集总热容模型。所有数字都是教学合成参数，不对应真实材料牌号、人体降温、食品安全或设备认证。这个模型最重要的工作，不是按计算器上的指数键，而是判断“一个温度代表整体”是否有依据。

若辐射不可忽略，可继续读辐射换热与线性化边界：分别保留空气温度和辐射环境温度，先列净功率，再判断能否冻结等效系数；旧文的对流时间常数不能直接当作含辐射过程的精确结果。

先检查近似内部扩散快，表面对流慢

用Biot数比较内部导热与边界换热，而不是仅凭“物体很小”决定能否使用集总模型。

再计算过程热阻 × 热容 = 时间常数

从能量守恒得到温度轨迹，核对初始值、长期极限、单位和累计散热。

一套假设对应一个温度变量

设物体起始温度均匀为T₀，体积V、密度ρ、比热c、导热系数k均为正常数。整个暴露面积Aₛ以相同且恒定的换热系数h与温度恒定为T∞的充分大流体环境换热；忽略辐射、内部热源、相变和物性随温度的变化，几何尺寸固定。

这些条件分工不同。大环境使T∞近似不随吸热改变；常h让边界传热规律保持线性；内部近似等温才允许用单个T(t)描述物体。若只有一部分表面暴露，Aₛ只计算该部分的有效换热面积，不能把绝热底面也一并加上。若不同表面的h或环境温度不同，需要分区求和，而不是悄悄复用同一个hAₛ。

C = ρVc｜热容
单位J/K；温度降低1K对应内能减少C焦耳。这里是总热容，不是比热c。
Rₕ = 1/(hAₛ)｜对流热阻
单位K/W；只描述物体与流体边界的换热，不代表物体内部没有任何温差。
Lc = V/Aₛ｜特征长度
单位m；本文Biot数与Fourier数统一采用这一定义，不能随意换成直径而不改数值。

从能量守恒推导指数变化

取离开物体的热流率为正，Q̇出=hAₛ(T−T∞)。物体内能变化率为C·dT/dt，守恒要求C·dT/dt=−Q̇出。冷却时温差为正，导数为负；若环境反而更热，两个符号同时反转，模型也能描述加热。

令θ=T−T∞，就有dθ/dt=−θ/τ。分离变量积分得到ln|θ(t)|−ln|θ(0)|=−t/τ，结合初始条件得到公式C1。T₀=T∞时直接得到常温解，不需要对零取对数。τ增大，温差衰减更慢；“密度更大散热更慢”只是在其余量固定时由热容增加得到的结论，不能跨不同几何和表面条件直接比较。

当t=τ，剩余温差是初始温差的1/e，约36.8%，并不是“降到初温的36.8%”。例如环境20°C、初温80°C，一个时间常数后的温度是20+60/e≈42.073°C。直接算80/e≈29.43°C，错在把摄氏温标原点当作物理零温差。

 A[物体内能变化] --> B[等于负的对流散热]
 B --> C[用单温度和恒定参数建模]
 C --> D[温差的一阶微分方程]
 D --> E[时间常数为热阻乘热容]
 E --> F[初始温差指数衰减]

先算Biot数，再信任这一条曲线

内部导热并不是瞬间发生的。用k衡量内部传热能力，h衡量边界换热能力，构造Bi=hLc/k。把同一量级的热流估算式hAₛΔT外与(kAₛ/Lc)ΔT内比较，可以理解为ΔT内/ΔT外约随Bi变化。Bi很小，内部温差相对于物体与环境的温差较小，才有理由忽略内部不均匀。

这是量级判断，不是对任何形状和任何时间都严格成立的误差上界。本文不把一个通用阈值宣称为“所有温度误差一定小于某百分比”的认证。若Bi不小、初始温度不均或局部热源显著，应转向空间分布的传热模型；表面测温也不必然等于内部平均温度。

重点C｜k不在温度解里，不等于k不重要

一旦接受近似，时间常数由C和hAₛ决定；但能不能接受这个近似，要用包含k的Biot数检查。把换热系数h提高很多，既会缩短预测时间，也可能破坏原本的单温度假设。

一组完整手算：多久到30°C

设V=10⁻⁶m³，Aₛ=6×10⁻⁴m²，ρ=2500kg/m³，c=800J/(kg·K)，k=100W/(m·K)，h=120W/(m²·K)，T₀=80°C，T∞=20°C。可把几何想象为边长1cm、六面均暴露的立方体，但参数仍是合成值。

由此m=ρV=0.0025kg，C=2J/K，hAₛ=0.072W/K，Rₕ=125/9K/W，τ=250/9s≈27.778s。Lc=1/600m，Bi=0.002，很小；α=5×10⁻⁵m²/s。这里几何与面积已明确，不能把1cm边长直接替代Lc，得到的Bi会相差六倍。

时刻 剩余温差比例 预测温度°C 累计散热J
0 1 80 0
τ≈27.778s e⁻¹≈0.367879 42.073 75.854
2τ≈55.556s e⁻²≈0.135335 28.120 103.760
3τ≈83.333s e⁻³≈0.049787 22.987 114.026

目标30°C位于初温与环境温度之间，温差比例是(30−20)/(80−20)=1/6，因此t*=τln6≈49.771s。比2τ稍短，与上表2τ时已经降到28.120°C一致。到达环境20°C则只在t趋于无穷时发生；若问“20°C附近”，必须给容许温差，不能把“附近”当成精确等号。

到30°C时，累计散热为2×(80−30)=100J；初始散热率为0.072×60=4.32W，目标时只有0.72W。用初始4.32W一直乘时间会高估散热，因为温差不断减小。全过程散热上限是C(T₀−T∞)=120J，也能用于发现单位或符号错误。

环境分两段时，温度不会跳变

前20s维持20°C环境，此后流体突然改为50°C，同时h仍为120。第一段末温T₁=20+60exp(−20/τ)≈49.205°C。环境发生阶跃，物体热容有限，物体温度仍连续；第二段应以49.205°C作为初值、以50°C作为新环境温度重新套用C1。

再经历20s，温度约为49.613°C。物体在第一段冷却，第二段反而缓慢升温，因为49.205低于新环境50。若第二段继续用80°C作初值，就等于凭空恢复了一份内能；若把T直接设成50°C，又把有限热容变成了零。

 A[第一段初温与环境] --> B[计算切换时刻的物体温度]
 B --> C[保持该温度作为第二段初值]
 C --> D[换用第二段的h与环境温度]
 D --> E[继续演化并核对能量变化]

改参数时，也要重新检查模型

把h提高100倍，其他参数不变，公式给出的τ缩短到约0.278s，但Bi同时变成0.2。不能只取“100倍更快”的好处，继续忽略内部温差。公式作为一个微分方程仍能计算，并不代表它仍能描述原物体。

若几何相似地将所有长度扩大两倍，体积增八倍、面积增四倍，恒定h及物性下τ增两倍，Bi也增两倍。这个结论是在“h保持不变”的假设下成立；真实流动中的h可能随尺寸、速度和温度变化，不能自动沿用。更不能仅靠质量翻倍就推断τ翻倍而忽略面积。

怎样审阅一份冷却计算

先在纸上画出物体、真正暴露的表面和环境，再写出参数单位。计算C与hAₛ后先核对τ是否为秒，随后计算Bi，才进入温度预测。对输出至少检查四件事：t=0回到初温；正时间温度保持在初温和恒定环境之间；冷却时温度单调下降；累计散热不超过有限内能差。

实验数据若明显偏离指数曲线，不应只调h把图“拟合得好看”。温度依赖物性、辐射、接触热阻、环境升温、内部温度分层和传感器滞后都可能贡献偏差。只凭一条曲线拟合出的τ，在C未知时也不能唯一识别h；只能得到hAₛ/C这一组合。

自检1：一个时间常数后温度是不是80/e？

不是。衰减的是相对环境的温差。该例应为20+60/e≈42.073°C，不能把摄氏温标的零点当作环境温度。

自检2：为什么k不出现在τ里，却仍要知道k？

τ是在内部近似等温的前提下推导的。k通过Bi=hLc/k决定这个前提是否有依据；舍去空间温差后，k才从单温度方程里消失。

自检3：两倍尺寸是否一定需要八倍冷却时间？

不是。几何相似且h不变时，热容增八倍，但换热面积也增四倍，τ只增两倍。Bi也翻倍，仍应重新核对近似。

自检4：环境从20突然变到50°C，物体温度会立即变50吗？

不会。有限热容要求温度连续，第二段继承第一段末温；变化的是新的驱动温差和温度导数。
