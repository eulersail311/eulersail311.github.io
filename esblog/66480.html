抽检十件零件，十件都通过。样本失败率是 0%，但基于样本比例估计标准误的 Wald 区间也给出 [0%, 0%]。同样零失败，抽了十件和抽了一百件显然提供了不同的证据。先看区间怎样反映样本量，再用重复抽样检查它实际能覆盖多少次。

让每个候选比例接受同一条检验

设 X 为 n 次相互独立、具有相同失败概率 p 的伯努利试验中的失败次数，样本比例 q=X/n。Wald 的标准误是 √[q(1−q)/n]，所以一旦 q 为 0 或 1，区间宽度就变成零。Wilson 使用候选比例 p₀ 对应的方差 p₀(1−p₀)/n，询问观测值与每个候选值的距离是否超过临界值。下面用双侧 95% 名义水平，取标准正态临界值 z≈1.96。

公式 W1 · 得分检验的接受条件

n(q−p₀)² ≤ z²p₀(1−p₀)。

对 0<p₀<1，这来自标准化得分的绝对值不超过 z。边界 p₀=0 或 1 直接按退化二项分布处理，恰好与此不等式相符。

展开得到 (n+z²)p₀²−(2nq+z²)p₀+nq²≤0。二次项系数为正，接受集位于两根之间，根可写成中心 c 加减半宽 h：

公式 W2 · 中心与半宽

令 a=z²/n，则 c=(q+a/2)/(1+a)，h=z√[q(1−q)/n+z²/(4n²)]/(1+a)。

区间为 [c−h, c+h]。中心可视为 q 与 1/2 的加权平均，样本比例仍为 q。

 A[固定观测次数与样本量] --> B[逐个检验候选失败率]
 B --> C[保留得分检验接受的候选值]
 C --> D[求二次不等式的两个端点]

同样零失败，区间上端差多少

当 q=0 时，W1 化成 p₀[(n+z²)p₀−z²]≤0。下端为 0，上端为 z²/(n+z²)。表中使用 z=1.96，百分比四舍五入到一位。

抽检件数 失败数 样本失败率 Wilson 双侧 95% 区间
10 0 0% [0%, 27.8%]
20 0 0% [0%, 16.1%]
100 0 0% [0%, 3.7%]

从失败计数算出两个端点

现在改成二十件里有两件失败。这次估计值 q=0.10，已经离开零边界，可以逐项跟着 W2 算。先得 a=3.8416/20=0.19208，把它代回中心得到 c=(0.10+0.09604)/1.19208≈0.16445。半宽用原始 q 计算，约为 0.13659。两者相减和相加，得到 [0.02787, 0.30104]。从点估计向下约走 7.21 个百分点，向上约走 20.10 个百分点。这个不对称性来自候选比例的不确定性随 p₀ 改变。

可以用 W1 独立验算。试 p₀=0.02，左侧为 20×0.08²=0.128，右侧为 3.8416×0.02×0.98≈0.0753，所以 2% 在下端之外。试 p₀=0.30，左侧为 0.8，右侧约为 0.8067，所以 30% 仍在里面。两个试值离样本比例的距离不同，一个只差 8 个百分点就被排除，另一个相差 20 个百分点仍能接受。

失败数 / 抽检数 样本失败率 原始 Wald 95% 区间 Wilson 95% 区间
1 / 10 10% [−8.59%, 28.59%] [1.79%, 40.42%]
2 / 20 10% [−3.15%, 23.15%] [2.79%, 30.10%]
10 / 100 10% [4.12%, 15.88%] [5.52%, 17.44%]

第一行里，若把 Wald 的负下端裁到 0，区间变成 [0%, 28.59%]，上端依旧低于 Wilson 的 40.42%。裁剪只改了显示边界。对于真实比例在 0 到 1 之间的覆盖率，裁到这个范围也不会改变一次区间是否覆盖它。两种区间的差异出在估计标准误与反演检验的步骤。

用端点再做两个检查。把失败改记成成功时，q 变为 1−q，W1 在 p₀→1−p₀ 下保持原样，所以新区间应当是 [1−上端, 1−下端]。当 n 大、q 远离边界时，a 变小，中心趋近 q，半宽的主项回到 z√[q(1−q)/n]。这说明两式会在大样本的内部区域接近，也说明为何边界小样本值得单独分析。

覆盖率可以用二项概率直接核对

假设真实失败率是 5%、n=10。把 p₀=0.05 和每种可能的 q=k/10 代入 W1，只有 k=0、1 时区间包含真实比例。因此这组参数下实际覆盖率是 0.95¹⁰+10×0.05×0.95⁹≈91.39%。换一个真实比例，能覆盖它的计数集合可能改变。95% 是构造区间时使用的名义水平，对一次已经算出的区间，应按这个频率学派的重复抽样规则解释。

把这一步写成通用账本。固定真实 p，让 k 从 0 枚举到 n。每个 k 对应区间 I(k)，出现概率为 C(n,k)pᵏ(1−p)ⁿ⁻ᵏ。只对满足 p∈I(k) 的行求和。计算 Wald 和 Wilson 时，二项权重完全相同，改变的是哪些行被计入。例子中的 C(n,k) 是选出 k 次失败位置的组合数，每一种位置排列的概率相同。

 A[固定真实比例和样本量] --> B[枚举可能的失败次数]
 B --> C[用每个计数构造区间]
 C --> D{区间覆盖真实比例}
 D -->|覆盖| E[计入这个计数的二项概率]
 D -->|未覆盖| F[本行贡献为零]
 E --> G[加总得到实际覆盖率]
 F --> G
真实失败率（n=10） Wilson 覆盖的失败次数 Wilson 实际覆盖率 Wald 实际覆盖率
1% 0 90.44% 9.55%
5% 0、1 91.39% 40.02%
10% 0 至 2 92.98% 64.97%
20% 0 至 4 96.72% 88.63%

真实比例为 1% 时，约九成试验都看见零失败。Wald 在这种观测下只给 [0,0]，恰好漏掉真实的 1%；Wilson 的 [0,27.8%] 能计入这批样本的概率。另一方面，表里也有 Wilson 覆盖超过 95% 的行。随着真实比例改变，某个整数计数会在区间端点进出接受集，它整行的概率也随之进入或退出求和。因此覆盖曲线会有跳变，几个示例点无法证明全参数范围的最低覆盖率。

自检 · 真实失败率为 5% 时，为什么 k=2 已超出接受范围？

左侧为 10×(0.2−0.05)²=0.225，右侧约为 0.1825。随着 k 从 2 继续增加，左侧只会更大。

自检 · 二十件全失败时，下端是多少？

交换成功与失败后，区间由 [0, 0.1611] 映射到约 [0.8389, 1]，也可直接在 W1 中代入 q=1。

从回顾区间走到事前抽样计划

考虑一种具体计划：事先规定只有零失败才报告单侧上界低于 1%。在边界 p₀=0.01 下，零失败的概率是 (1−0.01)ⁿ。若希望这一结果在该边界出现的概率至多为 5%，需解 0.99ⁿ≤0.05。两边取对数并除以负数 ln(0.99)，不等号反向，得到 n≥ln(0.05)/ln(0.99)≈298.07，因此至少 299 件。

同一问题也可反过来看：观察到零失败后，解 (1−U)ⁿ=α 得到精确单侧上界 U=1−α^(1/n)。十件零失败时，α=0.05 给出 25.89%；若要等尾双侧 95% Clopper–Pearson 区间，上端用 α/2=0.025，得到 30.85%。上一节的 27.8% 来自双侧 Wilson，比较三数时须同时说明尾部如何分配、检验用的是正态近似还是精确二项尾概率。

这份计划也没有承诺一定能通过。当真实失败率为 0.5%，299 件里零失败的概率只有约 22.3%。若希望真实水平为 0.5% 时大多能达标，应在事前为允许少量失败的规则另算通过概率和样本量。观察中途数据后追加抽样、反复尝试直到出现一批零失败，会改变实际使用的规则。

自检 · 把 299 件分为三批，只报告最漂亮的一批，可以沿用 299 件的上界吗？

报告单批结果时，参与该计数的样本量是那一批的件数；挑选最漂亮结果还引入了选择过程。若一开始就规定对全部独立、同分布的 299 件统一计数，才对应文中的固定样本方案。

报告前先核对抽样单位

同批零件共享工艺波动、同一个用户重复出现、停止规则由中途结果决定时，简单的固定 n 独立二项模型需要重新审视。报告应给出失败数、抽检数、抽样单位、区间算法和名义水平。若只需要单侧上界，先明确单侧覆盖目标，再选相应临界值。必须控制二项模型下的最小覆盖率时，可比较 Clopper–Pearson 的精确二项构造，代价通常是更保守的区间。

报告可以写成这样：在预先确定的 20 件独立抽检中观察到 2 件失败，样本失败率为 10%，Wilson 双侧 95% 区间为约 2.79% 至 30.10%。如果这 20 件全出自同一时段、同一批次，就把结论范围写成该抽样条件，避免直接外推到其他批次。若实际目标是跨批次质量，采样方案应先覆盖多个批次，分析时再处理同批件之间的关联。

阈值与基准率用比率说明分类指标的分母，配对 Bootstrap进一步讨论比较两个模型时如何保留同一抽样单位上的配对。本篇讨论一个二项比例。推导参照 NIST 技术说明 2119 §2.3、§3.4 和 §4.1，表格和覆盖率为教学算例。
