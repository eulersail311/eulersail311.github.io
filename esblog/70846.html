知识地图帮助找到文章，引用溯源帮助恢复结论的来路。还有一个问题：过了一段时间，关掉页面之后，自己还能解释它吗？

反复看到一句话，容易知道“在哪里看过”；面对一个新例子，却可能仍说不清条件。本文把复习分成两个可以分开检查的选择：这一次怎样练习，以及下一次何时再练习。用 Git 与 PCA 的已有内容做知识卡片，示范从阅读到闭卷回答、核对和修订的过程。

把问题留下，把答案暂时盖住。

再核对条件

用来源和判定标准检查回答。

最后安排时间

记录实际表现，再调整下一次。

熟悉感与提取，检查的是不同事情

重新阅读时，线索和答案同时在眼前。闭卷提取则先只保留问题，尝试从记忆中恢复解释、步骤或关系。两者都可能进入学习过程，但“看见答案觉得合理”不能直接充当“没有答案也能说清”的记录。

例如，读到“撤销合并并不会删掉祖先关系”时点头，并没有检查自己能否画出合并图。把页面关掉，重新画一次，再说明哪个父版本是比较基线，才能看到遗漏发生在哪一步。

这次做了什么 可以留下什么记录 这条记录还不能证明什么
重读一段说明 阅读位置、疑问、自己的释义 延迟后仍能独立解释
看选项后选出答案 该组线索下的选择 没有选项时也能生成回答
闭卷写出解释 核对前的实际回答与用时 回答一定正确、已经能迁移
对照来源并修订 遗漏的条件、改正的关系 下次已经记住这些修正
换情境再解释 新情境下的回答 所有实际任务都能熟练完成

这里的“提取”可以是写几句话、画一张关系图，或口述后留下简短记录，不要求每次背出原句。对需要精确措辞的内容，应事先写明标准；对概念解释，则应检查关系与条件，避免把措辞不同误判为错误。

原始研究支持什么，又没有替我们决定什么

Roediger 与 Karpicke（2006）让学生学习短篇说明材料，比较再次学习与自由回忆练习。练习中的回忆测试没有反馈；最终测试设置了不同延迟。该任务中，5 分钟后的表现较有利于再次学习，2 天或 1 周后的结果则较有利于先前的回忆练习。不能只用刚读完时的顺畅感判断较久之后的保持。原论文 PDF给出了材料、程序与结果；DOI用于定位发表版本。

这项比较不等于“阅读没有用”，也不能直接换算成本站 Git 或 PCA 卡片的收益。本文随后加入核对答案，是为了让个人练习能及时发现错误；没有把这个流程冒称为上述无反馈实验的完整复现。

Cepeda 等（2008）进一步研究了事实学习中两次学习之间的间隔，以及第二次学习到最终测试之间的保持间隔。结果显示，合适的学习间隔会随目标保持时间改变；间隔也不是一味越长越好。其任务材料和测试设计见 UCSD 托管原论文，发表版本为 DOI 10.1111/j.1467-9280.2008.02209.x。

因此，“采用分散的多次练习”和“给所有人规定同一组天数”是两件事。研究支持我们认真考虑时间安排，不能替每一种材料、每一个人和每一次考试直接给出通用最优日历。提取方式与时间间隔也不是同一个实验因素：今天连续做了几次闭卷回答，仍不等于已经进行跨天复习。

一张卡片，只留下一个能检查的问题

“学习 Git revert”范围太大，“PCA 是什么”又容易得到一句模糊定义。较实用的卡片应让人知道：当前给了什么条件，需要产出什么，以及怎样判定答案。

可以给每张卡片保留五项：问题、条件、答案要点、来源位置、修订日期。答案在尝试时折叠或盖住；来源帮助事后核读，不必从提取阶段就展示整段原文。卡片只是原文章的一个入口，不需要把长文章逐句拆成大量孤立问答。

下面两张卡片使用本站已有例子；它们没有记录真实读者的答题表现。

卡片 原来的宽泛提示 改写后的问题与条件 核对时需要的要点 来源
Git：撤销与历史 记住 revert 的用法 A 为初始版本；B 只打开功能；C 只更新独立说明。在 C 后撤销 B 成功得到 R。R 的父提交是谁？哪些内容保留？ R 的父提交是 C；功能回到关闭，C 的新说明保留；B 仍在祖先中。这里假定独立修改且成功应用 revert 的两个文件手算
PCA：误差口径 解释 80% 方差 原文四个中心化点的样本协方差谱为 32/3、8/3，n=4；保留第一方向。解释比例与总重构 SSE 各是多少？ 比例为 (32/3)/(40/3)=80%；SSE=(n−1)×8/3=8；80% 不是预测准确率 PCA 的四点例子

Git 卡片先练普通单父提交；若要复习合并主线，另建一张卡片，给出两个父版本并问“这次逆向修改相对哪个父版本计算”。不要在同一题里同时要求所有命令、冲突处理和再次合并的结论，否则答错后难以定位原因。

PCA 卡片给出了谱，所以它练的是解释率与重构误差的关系，没有检查从原始点求协方差的能力。需要检查推导时，另给四个坐标并要求画投影或重建矩阵；不能把已提供答案中间量的题目，算作完整掌握了所有步骤。

自检：PCA 卡片答出 80%，就算完整答对了吗？

没有。题目还问了总重构 SSE，应说明样本协方差采用 n−1 分母，所以舍弃谱之和需要乘 3，得到 8。只写 80% 漏掉了误差口径；即使两项都正确，这张卡片也没有检验从原始坐标求谱或在新任务上选维数的能力。

先记录原回答，再决定怎样改

练习前先写下两三个判定要点；回答时不要一边看答案一边补句子。核对时，把原回答保留下来，并单独标记改动。例如 Git 卡片若写成“回到 A”，应补上“C 的独立说明仍保留”，再核读原文的内容表与祖先图。

一种便于日常记录的做法是区分“独立完整”“提示后补全”“出现实质错误”“没有回答”。这是本文的记录约定，不是经过校准的心理测量分数。用时也只是辅助信息：快不等于理解深，慢不一定表示答错。

看到的情况 先检查什么 下一步可以怎样处理
关键关系正确且条件完整 是否只是认出了相同措辞 下次换一个数值或情境
结论对，理由说不出 问题是否只暗示一个术语 补问“为什么”，核读推导
反复漏掉同一条件 问题是否过宽，来源是否清楚 缩小问题，加入反例对照
看过提示才会回答 原记录是否保留了提示介入 标记为提示后补全，另约一次无提示尝试
多次完全想不起来 是否尚未理解，任务是否太大 回到解释或例子，再拆出小问题

不必为了“艰难”而一直卡在一道不会的题上。先作一次有记录的尝试，再看依据、解释错误，之后另找时间重新尝试。本文没有规定固定等待秒数，也没有把某种主观难度当作效果保证。

  B --> C[保存核对前的回答]

  D --> E{问题在哪里}

从间隔天数，落实到一份示例日历

下面假定 2026-10-22 完成初学，希望 11-12 再检查能否迁移。先安排 D1、D3、D7、D14 四次短练习。这是便于演示的计划，不是最优处方，也不是某位读者已经完成的实验记录。日期按相同本地时刻的日历日计算。

相对初学日计划日期距前一学习日这次安排预留时间
D02026-10-22—读懂例子，写卡片与核对标准8 分钟
D12026-10-231 天闭卷解释，再核对来源3 分钟
D32026-10-252 天保留原回答，重查遗漏条件3 分钟
D72026-10-294 天换一个数值或相邻情境3 分钟
D142026-11-057 天再作无提示尝试，整理待查项3 分钟

累计天数为 0、1、3、7、14，相邻间隔才是 1、2、4、7 天。初学 8 分钟加四次各 3 分钟，计划共 20 分钟；不含 D21（2026-11-12）的额外检验，也不含可能发生的补读。预算是预留量，实际花费应另外记录。

如果 D3 暴露了明显误解，先补读并修正，必要时提早下一次尝试，不必为了保住表格而机械等到 D7。如果临时错过一天，就记录实际日期，再安排后续；“原计划 D7”不能冒充实际间隔七天。若目标时间或任务难度改变，也应重新审视这份计划。

  flowchart LR
  G[确定想在何时做成什么] --> P[先排可执行的短练习]
  P --> R[到时闭卷尝试与核对]
  R --> L[记录实际日期与遗漏]
  L --> U[调整问题与下一次时间]
  U --> R
  L --> T[目标日期换情境检验]

检验会用，不能只看卡片通过次数

Git 卡片可以换成不同的修改关系：如果 C 恰好依赖 B 打开的功能，文本上成功撤销就能保证系统正常吗？回答应指出还需要检查语义依赖与行为。PCA 卡片可以改用另一组谱，或者让读者解释为什么测试集也必须使用训练均值。这些练习回到原文的条件，检验内容比背出同一组数字更宽。

若目标是实际操作，还应安排相应操作；若目标是写作，还应尝试不看笔记写一小段解释，再核对来源。卡片回答不能自动代替 Git 工作流演练、模型分析或完整论证。本文的卡片与迁移题是教学设计，没有实际测量学习效果，也没有证明它优于每个人当前的方法。

自检：把 D1、D3、D7、D14 写进日历，就已经完成间隔复习了吗？

没有。那只是初始计划。需要记录是否实际尝试、有没有看提示、怎样核对，以及实际发生的日期。即使四次都完成，也只能描述这些练习记录；是否达到目标，还要在目标任务与相应延迟下检查，不能从计划表推算个人保持率。

给下一次复习留下可用的入口

如果闭卷已经能回答单张卡片，却仍会在相似问题之间选错方法，可继续读交错练习与题型辨别。间隔回答“何时再练”，交错安排还追问“相邻练什么、是否需要自己判断方法”；两种安排可以同时存在，不能把混合次序本身当成掌握证据。

从一篇最近读过的文章开始，先写两张问题明确、答案有依据的卡片。保留核对前的回答，把修订与原回答分开，并给下一次尝试留一个真实可执行的时间。若一张卡总答不好，先检查问题与理解，不急着增加卡片数量。

继续用知识地图连接文章，用引用溯源维护答案的证据；用 Git revert和 PCA检查本文两张卡片的完整上下文。内部核验见 tests/verify-retrieval-notes-article.cjs：只核对文章结构、来源定位、示例算术与图示一致性，不把页面检查当作人类学习实验。
