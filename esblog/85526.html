Fick 扩散 从浓度梯度到长度与时间尺度

一级衰减与 Arrhenius讨论某个量怎样随时间变化。材料里的另一类问题还要追问位置：某处浓度降低，是反应消耗了物质，还是物质流到了别处？两者都可能产生下降曲线，需要用守恒与边界条件分开。

本文使用一维、固定截面、静止介质中的单一扩散组分模型：扩散系数 D 为正的常数，无反应、无体积流动，局部关系用标量 D 描述。全部参数和曲线都是教学合成算例，不对应特定材料，也不用于预测真实器件寿命。

先把浓度、梯度和通量分开

浓度 c(x,t) 表示单位体积里的物质量；这里采用 mol/m³。浓度梯度 ∂c/∂x 表示沿正 x 方向每走一米，浓度怎样改变。通量 J 表示单位面积、单位时间穿过截面的物质量，单位是 mol/(m²·s)，带符号的 J 指沿正 x 方向的分量。

Fick 第一定律在本篇范围内写为：

J = −D ∂c/∂x，其中 D 的单位是 m²/s。

负号把“沿浓度升高的方向”和“净扩散通量方向”区分开。若左边浓度高、右边低，则沿向右的 x 方向有 ∂c/∂x＜0，于是 J＞0，净通量向右。它描述宏观净传输，不表示所有粒子只朝一个方向运动。MIT 传输现象讲义以通量关系、守恒和边界条件组织这类问题。

检查单位可以及时发现把浓度差当成梯度的错误：m²/s × mol/m⁴ = mol/(m²·s)。若只用两端浓度差 Δc，仍需除以距离；总传输率还要将 J 乘以截面积。

局部守恒怎样给出第二定律

取截面积 S、厚度 Δx 的小体积。左面流入 J(x)S，右面流出 J(x+Δx)S；没有内部生成或消耗时，物质量增长率为两者之差：

SΔx ∂c/∂t = S[J(x) − J(x+Δx)]。

除以体积并令 Δx 趋近于零：∂c/∂t = −∂J/∂x。

代入第一定律，先得到 ∂c/∂t = ∂[D ∂c/∂x]/∂x；只有在 D 不随位置或浓度变化的本篇条件下，才化为 ∂c/∂t = D ∂²c/∂x²。这就是这里使用的 Fick 第二定律。UC Berkeley 教材也从组分收支区分扩散项与反应项。

曲率而非斜率决定此处浓度是否随时间改变。直线有非零斜率，却没有曲率：流入与流出相等，可以持续传输而不再积累。局部峰附近曲率为负，浓度趋于下降；局部谷附近曲率为正，浓度趋于上升。

  flowchart LR
  A[确定正方向与浓度单位] --> B[梯度决定带符号通量]
  B --> C[小体积流入减流出]
  C --> D[局部守恒方程]
  D --> E{D是否为常数}
  E -- 是 --> F[时间变化等于D乘浓度曲率]
  E -- 否 --> G[保留D在空间导数内部]

“第一定律只在稳态成立”也容易误导：本篇把它作为局部通量关系，在随时间变化的剖面上同样使用；稳态是额外要求 ∂c/∂t=0。

一条直线怎样手算稳态通量

取厚度 L=10⁻⁴ m，也就是 100 μm，D=10⁻¹² m²/s。两端由储库固定为 c(0)=3 mol/m³、c(L)=1 mol/m³。稳态方程 c″=0 给出：

c(x) = 3 − 2x/L；∂c/∂x = −2/L = −20000 mol/m⁴。

J = −10⁻¹² × (−20000) = 2×10⁻⁸ mol/(m²·s)。

正号说明通量沿正 x 方向。若交换两端浓度，J 变为负值；若两端相等且已达稳态，J 为零。此时让厚度加倍，在 D 和两端浓度都相同的条件下，稳态通量减半。

这里的线性解要求平板几何与固定截面。圆柱径向扩散的面积随半径改变，需要重新写守恒，不能把整个半径区间直接当成同一块平板。

L²/D 为什么只是时间尺度

在扩散方程中，时间变化约为浓度变化量除以时间，空间二阶变化约为浓度变化量除以 L²；配平后得到 t 与 L²/D 同阶。也可以令 ξ=x/L、θ=Dt/L²，方程就成为 ∂c/∂θ=∂²c/∂ξ²。

这说明相同无量纲几何、边界与初始形状下，长度加倍会把同类演化时间放大四倍。它没有指定“演化到哪个阈值”，也没有指定初始剖面，因此不能把 L²/D 写成所有样品精确相同的稳定时间或寿命。对于无限空间单粒子均方位移、有限薄层的模态衰减等不同定义，常数因子会不同。

以下选一个能直接代入检验的解析解，让那个常数因子来自明确的边界和初始条件。

固定两端浓度的精确衰减模态

这次两端都固定为同一个 c₀，并设初始剖面 c(x,0)=c₀+A sin(πx/L)，其中 0≤x≤L、c₀≥0、A＞0。解取为：

**c(x,t) = c₀ + A exp(−Dπ²t/L²) sin(πx/L)**。

在 x=0、L 处正弦为零，所以边界始终为 c₀；在 t=0 时恢复给定初始剖面。对时间求导会带出 −Dπ²/L²，对空间求两次导会带出 −π²/L²，两者满足扩散方程。这是该初始形状的精确解，不是把任意初始剖面都替换成一条正弦。

定义幅度 a(t)=A exp(−t/τ)，得到：

**τ = L²/(π²D)**：幅度降到初始值 1/e 的时间。

t_half = ln(2)τ：过量浓度 c−c₀ 的幅度减半时间。

半幅时间折半的是相对 c₀ 的偏离，不是将总浓度 c 折半。一般初始剖面可能包含多个正弦模态，第 n 个模态的时间常数是 L²/(n²π²D)；各项混合时，某点的初期变化通常不是单一指数。

把尺度、时间常数和半幅时间放在一张表

L / μm D / (m²/s) L²/D / s τ=L²/(π²D) / s t_half=ln(2)τ / s
100 10⁻¹² 10000 1013.21 702.30
200 10⁻¹² 40000 4052.85 2809.22
100 2×10⁻¹² 5000 506.61 351.15

第一行的 τ 约 16.89 分钟，半幅时间约 11.71 分钟；它们都不是 L²/D≈166.67 分钟。τ 时幅度剩约 0.367879，2τ 时剩约 0.135335。D 加倍把同一模型的所有对应时间减半，但这里没有测量真实材料 D，也没有假设所有材料的 D 都相同。

固定浓度边界为什么允许物质离开

上面的正弦峰在左右两端都朝外输运。其通量为 J=−DAπ/L × exp(−t/τ) cos(πx/L)：左端为负，右端为正。负的左端分量表示物质向左流入储库，正的右端分量表示物质向右流入储库。

单位截面积内的过量物质量为 M_ex=∫₀ᴸ(c−c₀)dx = 2AL/π × exp(−t/τ)。直接求导可得 **dM_ex/dt=J(0)−J(L)**。内部没有反应消耗，薄层内总量仍会因为边界流出而减少；把储库一并纳入时，物质并没有凭空消失。

若改为封闭无流边界 J(0)=J(L)=0，总量守恒。任意给定初始剖面可以在适当正则性条件下朝其空间平均浓度变平，但平均浓度不会被外部储库固定为 c₀。本篇的正弦初始剖面在端点具有非零导数，不能原样当作满足无流边界的同一个解析模态。

  flowchart TD
  A[观察浓度随时间下降] --> B{物质是否可越过边界}
  B -- 固定浓度储库 --> C[用端点通量计算净流出]
  B -- 封闭无流 --> D[总体物质量保持不变]
  C --> E[无反应也能减少层内物质量]
  D --> F[局部下降由其他位置上升补偿]
  E --> G[再检查是否需要加入反应与对流]
  F --> G

使用模型前的边界与自检

需要确认的条件 本文选择 条件改变后要检查什么
几何 一维平板、固定截面 径向几何的面积因子
输运机制 纯扩散、静止介质 对流、电场与交叉耦合
扩散系数 标量、恒定且 D＞0 温度、组成、位置或方向依赖
内部源汇 无反应 反应项与传质的共同作用
边界 显式指定储库浓度或无流 表面交换是否足够快
时间指标 模态幅度的指定阈值 初始剖面与测量量是否一致

对于钙钛矿材料中的离子相关现象，浓度梯度可能只是驱动因素之一；电场、缺陷、界面和组分耦合需要额外模型与证据。本篇纯扩散算例不能直接替代真实器件解释。

自检：浓度沿向右方向下降，通量与浓度变化率一定都为正吗？

通量 J 为正，表示净传输向右；浓度变化率取决于通量差或浓度曲率。线性稳态剖面的浓度变化率为零，即使通量持续为正。

自检：这组算例里半幅时间约702秒，能称为材料的反应半衰期吗？

不能。这里没有反应，固定浓度储库从两端接收物质；702.30秒描述指定厚度、D、边界和初始正弦模态的过量幅度折半。换成封闭边界或其他初始形状，就需要重新求解和定义指标。

内部检查位于 tests/verify-diffusion-article.cjs：核对单位对应的手算数值、解析模态导数和边界通量收支，并用独立守恒离散推进检查误差随网格细化而下降。图中的数据与坐标也逐点核验。这些检查验证教学模型的计算与图示一致，没有验证某种材料参数、实际扩散机制或寿命预测。
