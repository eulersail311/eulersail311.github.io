古典音乐中的和声张力：从功能和声到终止式

发表于2026-09-01|更新于2026-09-02|音乐随笔
|字数总计:2.7k|阅读时长:8分钟|页面浏览量:

旋律告诉我们“谁在说话”，和声则常常决定一句话是否已经说完。即使不知道和弦名称，我们也能听见某些时刻像站稳、像离开、像等待，或者像终于回到原点。这种方向感，是理解功能和声最自然的入口。

本文不把和声简化成“某个和弦等于某种情绪”，而是把它看成时间中的作用关系：同一个和弦放在不同调性、音区、节拍和上下文里，意义都可能改变。

1. 和声张力不是音量

音乐变紧张，不一定要更响、更快或使用更多乐器。一个很轻的和弦也可能因为迟迟不解决而充满悬念；一段厚重的全奏也可能已经稳定地落在终点。

判断和声张力时，可以先问三个问题：

  1. 当前声音是否让人愿意停住；
  2. 它是否像在推动下一步；
  3. 下一和弦出现后，之前的期待有没有得到满足。

所以张力不是单个和弦的固定属性，而是前后关系产生的听觉预期。

2. 三类基本功能

在大、小调功能和声中，常用三个功能区域描述方向。罗马数字表示和弦建立在调式的第几级上，并不是另一套音名。

功能区域 常见级数 听觉作用 可以想象成
主功能 Tonic I，有时包含 vi、iii 确立或延长稳定中心 家与地面
下属/前属功能 Predominant IV、ii 离开中心，为属功能准备 出发与转弯
属功能 Dominant V、vii° 集中方向，要求解决 门前与问号

最典型的功能路线可以写成：

  flowchart LR
    T1[主功能 T<br/>稳定] --> P[前属功能 PD<br/>离开]
    P --> D[属功能 D<br/>紧张]
    D --> T2[主功能 T<br/>解决]
    T1 -.延长.-> T1
    D -.暂不解决.-> D

这不是所有音乐都必须遵守的公式。它更像一张基础地图：先学会辨认清楚的道路，之后才容易听见作曲家在哪里绕路、隐瞒终点或故意不回家。

3. 为什么属和弦如此想要解决

以 C 大调为例，主和弦是 C–E–G，属和弦是 G–B–D。属和弦中的 B 距离主音 C 只有半音，耳朵很容易期待 B 上行到 C；低音 G 也常以五度关系回到 C。

如果属七和弦再加入 F，F 往往倾向下行到 E。于是两条方向同时出现：

  • B → C，向上半音；
  • F → E，向下半音。

这种“外层收拢”的声部运动让 V7 → I 的解决格外清晰。真正产生方向感的，不只是两个和弦的名称，也是各声部怎样用最短路径移动。

4. 四种常见终止式

终止式可以理解为乐句末尾的标点。判断它时，既要看最后两个功能，也要听低音、最高声部和节拍位置。

正格终止：属到主

V → I 是最明确的回归。若两个和弦都处于根音位置，主和弦最高声部又落在主音上，句号感通常最强；其他配置仍然可以形成正格终止，但闭合程度较弱。

半终止：停在属功能

乐句结束在 V，像话说到一半。它经常出现在一对乐句的前一句，留下继续前进的需要。半终止的重点不是“哪个和弦来到属”，而是终点本身仍然不稳定。

变格终止：下属到主

IV → I 常被称为变格终止。它没有 V → I 那样尖锐的导音解决，收束较柔和，也常出现在更强终止之后，像句号后的余韵。

阻碍终止：期待被改道

属功能已经建立，耳朵等待 I，结果却来到 vi 等其他和弦。期待没有消失，只是被延长。这种 V → vi 的走向常被称为阻碍终止或欺骗终止。

  flowchart TD
    A[乐句接近结尾] --> B{最后停在哪里}
    B -- V → I --> C[正格终止<br/>明确回归]
    B -- 停在 V --> D[半终止<br/>等待下文]
    B -- IV → I --> E[变格终止<br/>柔和收束]
    B -- V → vi --> F[阻碍终止<br/>期待改道]

5. 低音为什么比和弦标签更值得先听

初学和声分析时，很容易只盯着每一拍的罗马数字。真实聆听中，低音往往更早暴露方向：它决定和弦的根基，也能通过级进、五度跳进或持续音塑造长线条。

同一个主和弦如果把三音或五音放在低音，稳定程度会改变；同一组上方音如果放在不同低音上，甚至可能属于不同和弦。练习时可以先忽略内声部，只哼低音的移动：

  • 是否围绕主音停留；
  • 是否向属音推进；
  • 是否在终止前出现明显的五度关系；
  • 是否用持续低音让上方和声不断换色。

当低音路线被听见以后，再加入旋律，纵向和弦会更容易落在时间轴上。

前四小节从主功能出发，经前属功能来到属功能；第五小节没有立刻回到 I，而是落到 vi，形成一次温和的阻碍。随后 ii → V → I 重新建立并完成终止。

可以到 音乐实验室 点击《归港》，分三遍听：

  1. 第一遍只判断哪些位置像“站稳”或“悬着”；
  2. 第二遍跟随低音，留意第五小节为什么没有真正结束；
  3. 第三遍比较第一次属功能和最后一次属功能，听后者为何更像终点前的准备。

曲目由浏览器使用 Web Audio API 即时合成，不加载外部录音。简单的音色反而有利于把注意力放在低音与和声方向上。

7. 四遍和声聆听法

面对一段陌生作品，不必第一遍就写完整和弦分析。

第一遍：标出呼吸

只记录乐句在哪里停顿。身体是否自然想换气，通常比小节线更能提示句法边界。

第二遍：判断开合

每个停顿是已经结束，还是还在等待？先写“开”与“合”，不急着判断终止式名称。

第三遍：跟随低音

尝试哼出最低声部的关键节点，尤其留意主音、属音和终止前的跳进。

第四遍：验证功能

最后再用 T–PD–D–T 或罗马数字解释听感。如果标签和实际听感冲突，应回到谱面、声部进行与节拍位置重新检查，而不是强迫耳朵服从标签。

8. 几个常见误区

  • 大调等于快乐，小调等于悲伤：调式只是色彩的一部分，速度、音区、织体和语境同样重要；
  • 看到 V 就一定紧张：属和弦若处于弱拍、经过位置或长期持续，作用可能被削弱；
  • 终止式只看最后两个和弦：低音位置、旋律终点和节拍强弱都会改变闭合程度；
  • 功能分析适用于全部音乐：调式音乐、印象主义和声、无调性音乐与很多非西方传统需要其他分析框架；
  • 分析越细越接近聆听：标签的目的，是解释听到的方向，而不是替代声音本身。

9. 从方向感进入更大的结构

当我们能听见稳定、离开、紧张和解决，大型曲式就不再只是抽象分段。转调意味着“家”的位置改变，再现意味着熟悉材料与稳定中心同时回归，尾声则可能一次次确认已经抵达。

和声分析最有价值的时刻，不是准确说出每一个和弦，而是在音乐尚未到达时，耳朵已经知道它正朝哪里走。

10. 应用属和弦：临时照亮另一个目标

属功能不只可以指向全曲主音。作曲家也能暂时把某个调内和弦当作局部目标，在它前面放置属于该目标的属和弦，这就是应用属和弦或副属和弦。

以 C 大调为例，D 大三和弦或 D7 含有调外音 F♯，它强烈指向 G：

D7 中的 F♯ 倾向上行到 G，C 倾向下行到 B，于是 G 和弦短暂获得了类似“主和弦”的聚光灯。但整体很快回到 C，原来的主中心并没有真正消失。

聆听调外音时，不要立即把它理解成错误或彻底转调。先观察它是否形成了清楚的半音趋向，又是否在下一和弦得到解决。许多和声色彩，正来自临时强化某个局部目标。

11. 主化与转调怎样区分

主化是短暂把另一个和弦当作目标；转调则让新的调性中心在结构上站稳。两者之间不是绝对开关，但可以从证据强度判断：

线索 更像短暂主化 更像已经转调
持续时间 一两个和弦后回到原调 新中心持续多个乐句
终止 只有一次局部属到主 在新调形成明确终止
调号外音 只服务于一次趋向 多个声部持续采用新调音级
结构位置 经过、装饰或局部强调 新主题、段落或重要边界

实际聆听时，可以暂停罗马数字分析，只问：“刚才像是短暂拜访，还是房间的地面真的换了方向？”随后再用终止、低音和持续时间验证。这个顺序能避免看到一个升降号就宣布转调。

一个五分钟练习

  1. 在钢琴或虚拟键盘上依次弹 C–Am–D7–G–C；
  2. 第一遍只听 D7 出现时颜色为何突然变亮或变尖；
  3. 第二遍只追 F♯→G 与 C→B 两条半音线；
  4. 第三遍停在 G，感受它能否暂时成为终点；
  5. 最后补上 C，比较“局部抵达”和“回到全局中心”的差别。

功能和声的学习重点始终是可听见的方向。标签 V7/V 只是把这条方向压缩成一种便于交流的记号。
